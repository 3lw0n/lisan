# لِسان (Lisan)

تطبيق جوال يعلّم **غير الناطقين بالعربية** القراءة **من الحروف**، ويعمل **بلا إنترنت**.

## ما هو
رحلة واحدة واضحة: من الحرف وصوته، إلى الكتابة، إلى أول نصّ يقرؤه المتعلّم بنفسه.
- صوت مضمَّن داخل التطبيق (لا يحتاج شبكة)
- تغذية راجعة فورية على الكتابة بقواعد ثابتة
- تسمّع النطق يعمل على الجهاز، ولا يُرسل الصوت خارج التطبيق
- بلا حساب إلزامي، وبلا إعلانات، وبلا مشتريات داخلية

## الحالة
- الإصدار الحالي: **v0.1.5** (المرحلة ١ · وآخر ثلاث ترقيمات لإصلاح هوية الأيقونة والشعار) قبل المرحلة القادمة **٤ إلى ٦ أكتوبر ٢٠٢٦**.
- الإصدار الأول: **Android** (Release 1.0)، وiOS لاحقًا من نفس الشيفرة.

## ما يعمل الآن فعلًا (المرحلة ١)
- **لوحة الحروف**: شبكة الحروف الـ٢٨ بأربعة أعمدة، مبنية من `assets/data/letters.csv`.
- **شاشة الحرف**: الحرف كبيرًا، ومكان الأشكال الأربعة (أول · وسط · آخر · منفصل)، وزر صوت الحرف، وكلمة المثال ومعناها.
- **التقدّم محفوظ على الجهاز فقط** (زر «أتممتُ هذا الحرف»، والحرف المكتمل يتلوّن في اللوحة) بلا حساب ولا خادم.
- واجهة عربية RTL من الجذر، وAndroid 8 فأحدث (`minSdk = 26`).

## ما لم يُبنَ بعد (بصراحة)
- **لا توجد أي أصول بعد**: لا أصوات ولا صور أشكال ولا صور كلمات، ولا خط عربي مضمَّن (النص بخط النظام الافتراضي). مكان كل أصل غائب يظهر إطار «لم يُضف بعد» أو «الصوت لم يُضف بعد»، وفي وضع التطوير يُطبع المسار الناقص.
- `letters.csv`: الحروف وأسماؤها اللاتينية وكلمة مثال لكل حرف بمعناها الإنجليزي (٢٨ صفًّا) · تفصيل المساعدة اللغوية في `THIRD_PARTY.md`.
- الكتابة والقواعد والتسمّع والحساب والنقاط والقصص والتقرير: غير مبنية (انظر `التوثيق`).

## الأصول
تُضاف مجلدات الأصول مع وصول ملفاتها.
- المسارات التي يبحث عنها التطبيق لكل حرف (`name_en` من `letters.csv`، بحالة أحرف مطابقة):
  `assets/audio/letters/<name_en>/sound.mp3` · `assets/images/letters/<name_en>/forms/{initial,medial,final,isolated}.png` (كلمة المثال ومعناها نصّ من `letters.csv` بلا صورة)
- أسماء `name_en` مطابقة لجدول القسم ٣ في «مواصفة الأصول» ولا تُغيَّر.
- عند وصول ملف: ضعه في مساره، ثم أضِف سطر مجلده تحت `flutter: assets:` في `pubspec.yaml` (إعلان مجلد غير موجود يُفشل البناء).

## التقنية
- **Flutter / Dart** · Android SDK 36 · Web للتطوير السريع
- كل الوظائف الأساسية مصمّمة لتعمل على الجهاز بلا إنترنت.

## التشغيل
```bash
flutter pub get
flutter test                # اختبارات الشاشتين والتقدّم والأصول الغائبة
flutter run -d chrome       # معاينة سريعة في المتصفح
flutter run                 # جهاز أندرويد أو محاكي
flutter build apk --debug   # بناء ملف APK للتجربة
```
